# Engineering Robustness — 工程健壮性规范

> 本 skill 是**设计+实现+审查**的完整参考。
> 架构师阶段2设计 → 开发阶段6实现 → 审查者阶段7验证，三个角色共用同一份规范。

---

## 1. 前端防抖/节流

### 设计表（架构师填入 ARCHITECTURE.md）

| 场景 | 策略 | 延迟 | 说明 |
|------|------|------|------|
| 提交按钮 | 防抖 + loading 状态 | 300ms | 防止重复提交 |
| 搜索输入 | 防抖 | 500ms | 输入停止后发请求 |
| 滚动加载 | 节流 | 200ms | 限制触发频率 |
| 窗口 resize | 节流 | 300ms | 避免频繁重排 |
| 表单自动保存 | 防抖 | 2000ms | 用户停止编辑后保存 |

## 2. 分布式锁/并发控制

### 设计表

| 场景 | 方案 | 说明 |
|------|------|------|
| 库存扣减 | Redis 原子操作 | 防止超卖 |
| 订单创建 | 唯一约束 + 幂等键 | 防止重复下单 |
| 状态流转 | 乐观锁（版本号） | 防止并发覆盖 |
| 定时任务 | Redis 分布式锁 | 防止多实例重复执行 |

## 3. 边界条件

### 设计表

| 边界类型 | 处理方式 |
|---------|---------|
| 空值输入 | 必填字段校验，返回 400 + 具体字段名 |
| 空集合 | 返回空数组 `[]`，不返回 null |
| 分页边界 | `page<1` 修正为 1，`size>100` 修正为 100 |
| 字符串超长 | 截断或 400，前端实时计数提示 |
| 数值溢出 | 后端 BigDecimal/Long |
| 日期边界 | 起止日期互换校验，时区统一 UTC+8 |
| 并发冲突 | 返回 409 Conflict |
| 资源不存在 | 返回 404 + 具体资源类型 |

## 4. 超时设计

| 调用类型 | 建议超时 | 说明 |
|---------|---------|------|
| HTTP 外部 API | 连接 3s，读取 10s | 第三方接口不可控 |
| 数据库查询 | 30s | 慢查询告警阈值 |
| Redis 操作 | 连接 1s，读写 2s | 通常毫秒级 |
| 文件上传 | 30s | 大文件走分片 |
| 消息队列发送 | 5s | 超时后进重试队列 |
| 内部服务调用 | 连接 2s，读取 5s | 必须熔断+超时 |

---

## 5. 缓存策略

| 场景 | 问题 | 方案 |
|------|------|------|
| 缓存穿透 | 查询不存在的数据 | 布隆过滤器 / 缓存空值（TTL=60s） |
| 缓存雪崩 | 大量 key 同时过期 | 过期时间加随机偏移 |
| 缓存击穿 | 热 key 过期 | 互斥锁 / 永不过期+异步刷新 |
| 缓存一致性 | DB 更新后缓存未同步 | Cache Aside（先更新 DB，再删缓存） |
| 热 key | 单 key QPS 过高 | 本地缓存 / key 拆分 |

---

## 6. 限流

| 维度 | 策略 | 说明 |
|------|------|------|
| 接口级 | 令牌桶 / 滑动窗口 | 单接口 QPS 上限 |
| 用户级 | 令牌桶 | 单用户每分钟请求数 |
| IP 级 | 滑动窗口 | 防爬虫 |
| 全局 | 计数器 | 系统总 QPS 保护 |

超限返回 HTTP 429 + `Retry-After` 头。

---

## 7. 文件上传安全

| 检查项 | 说明 |
|--------|------|
| 文件类型 | 白名单校验（content-type + magic bytes） |
| 文件大小 | 单文件上限（如 10MB），超限返回 413 |
| 文件名 | 重命名为 UUID，防路径穿越 |
| 存储路径 | 禁止用户控制，统一存到 OSS |
| 病毒扫描 | 生产环境接入扫描服务 |
| 访问权限 | 默认私有，需签名 URL |

## 8. 连接池配置

| 组件 | 关键参数 | 建议值 |
|------|---------|--------|
| 数据库（HikariCP） | maximumPoolSize | CPU 核心数 × 2 + 磁盘数 |
| 数据库（HikariCP） | connectionTimeout | 3000ms |
| Redis（Lettuce） | maxTotal | 50-100 |
| HTTP Client | maxConnectionsPerRoute | 50 |

## 9. 优雅降级

| 场景 | 降级策略 |
|------|---------|
| 搜索服务不可用 | 返回"搜索暂时不可用" |
| 推荐服务超时 | 返回默认推荐列表 |
| 短信发送失败 | 进重试队列（指数退避，5次上限） |
| 第三方登录不可用 | 隐藏入口，仅保留账号密码 |

---

## 10. 数据脱敏

| 场景 | 脱敏规则 |
|------|---------|
| 日志输出 | 手机号 `138****1234`，密码不记录 |
| API 响应 | 邮箱 `t***@example.com`，银行卡 `****1234` |
| 数据库存储 | 密码 bcrypt，敏感字段 AES |
| 前端展示 | 输入框 type=password |

---

## 11. 幂等性设计

| 场景 | 幂等方案 |
|------|---------|
| 创建操作 | 幂等键（前端 UUID），后端唯一约束 |
| 更新操作 | 乐观锁（WHERE version=?） |
| 删除操作 | 软删除 + 唯一约束 |
| 支付回调 | 订单状态机 |
| 消息消费 | 消费端去重表 |
