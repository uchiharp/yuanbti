|------------|--------|------|------|
| 400 | SYS_001 | 参数校验失败 | {格式} |
| 401 | AUTH_001 | Token过期 | {格式} |
| 403 | PERM_001 | 无权限 | {格式} |
| 404 | {模块}_001 | 资源不存在 | {格式} |
| 500 | SYS_100 | 系统内部错误 | {格式} |

### 核心接口

#### {POST /api/v1/users} — 创建用户

**请求：**
```json
{
  "username": "string",
  "email": "string",
  "password": "string"
}
```

**响应：**
```json
{
  "code": "SUCCESS",
  "data": {
    "id": 1,
    "username": "test"
  }
}
```

**错误码：**
- `USER_001`: 用户名已存在
- `SYS_001`: 参数校验失败

## 10. 日志/异常/错误处理

### 异常传播策略

| 层 | 异常处理 |
|---|---------|
| Controller | 不捕获，交给全局异常处理器 |
| Service | 捕获业务异常，不捕获系统异常 |
| Repository | 不捕获，让异常冒泡 |

### 日志规范

- 结构化日志（JSON 格式）
- 每条日志包含：timestamp, level, traceId, userId, action, module, message
- ERROR 必须带堆栈

### 审计日志

- 敏感操作记录：user_id, action, resource, resource_id, detail, ip
- 实现方式：AOP 切面 + @AuditLog 注解
